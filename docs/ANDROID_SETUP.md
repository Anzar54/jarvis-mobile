# How to Install Jarvis on Your Android Phone\n\n## Quick Start (Easiest Way)\n\n### Option 1: Using Expo Go App (Development)\n\nThis is the fastest way to test Jarvis on your phone.\n\n#### Step 1: Install Expo Go\n1. Open Google Play Store on your Android phone\n2. Search for **\"Expo Go\"**\n3. Install it\n\n#### Step 2: Set Up on Your Laptop\n\n1. Open Command Prompt on your Windows laptop\n2. Navigate to the jarvis-mobile folder:\n   ```bash\n   cd jarvis-mobile\n   ```\n\n3. Install dependencies:\n   ```bash\n   npm install\n   ```\n\n4. Start the development server:\n   ```bash\n   npm start\n   ```\n\n   You'll see a QR code in the terminal.\n\n#### Step 3: Open in Expo Go\n1. Open **Expo Go** on your Android phone\n2. Tap the **QR code icon** (bottom right)\n3. Point your phone camera at the QR code from your laptop screen\n4. The app will load automatically\n\n---\n\n### Option 2: Build an APK (Install Like a Regular App)\n\nThis creates a proper Android app file that you can share and install.\n\n#### Step 1: Install EAS CLI\nOn your laptop:\n```bash\nnpm install -g eas-cli\n```\n\n#### Step 2: Sign In to Expo\n```bash\neas login\n```\nCreate a free account at [expo.dev](https://expo.dev) if you don't have one.\n\n#### Step 3: Build the APK\n```bash\ncd jarvis-mobile\neas build --platform android --profile preview\n```\n\nThis will build your app in the cloud. Wait for it to finish (5-10 minutes).\n\n#### Step 4: Download the APK\n1. Go to [expo.dev](https://expo.dev) and log in\n2. Find your build in the dashboard\n3. Download the APK file\n4. Send it to your phone (via email, WhatsApp, etc.)\n\n#### Step 5: Install on Phone\n1. On your Android phone, open the downloaded APK file\n2. Tap **Install**\n3. Allow permissions when asked\n4. Open the app from your home screen\n\n---\n\n## Connect to Your Windows Jarvis\n\nBy default, the mobile app only has basic local commands (time, date).\n\nTo connect it to your Windows Jarvis for full AI responses:\n\n#### Step 1: Find Your Laptop's IP Address\nOn your Windows laptop, open Command Prompt:\n```bash\nipconfig\n```\n\nLook for **IPv4 Address** (something like `192.168.1.20`)\n\n#### Step 2: Update the Mobile App\nEdit the file `App.tsx` in your jarvis-mobile folder.\n\nFind this line:\n```typescript\nconst DESKTOP_URL = ''; // Optional\n```\n\nChange it to:\n```typescript\nconst DESKTOP_URL = 'http://192.168.1.20:8000/ask'; // Replace with your laptop IP\n```\n\n#### Step 3: Start Your Windows Jarvis\nOn your Windows laptop:\n```bash\ncd jarvis-assistant\nvenv\\Scripts\\activate\npython main.py test\n```\n\n#### Step 4: Run a Web Server (Optional)\nYour Windows Jarvis needs to expose an HTTP endpoint. Create a file `server.py` in your `jarvis-assistant` folder:\n\n```python\nfrom flask import Flask, request, jsonify\nfrom src.jarvis import Jarvis\n\napp = Flask(__name__)\njarvis = Jarvis()\n\n@app.route('/ask', methods=['POST'])\ndef ask():\n    data = request.json\n    prompt = data.get('prompt', '')\n    response = jarvis.llm.generate(prompt)\n    return jsonify({'response': response or 'I could not generate a response.'})\n\nif __name__ == '__main__':\n    app.run(host='0.0.0.0', port=8000, debug=False)\n```\n\nInstall Flask:\n```bash\npip install flask\n```\n\nRun the server:\n```bash\npython server.py\n```\n\nNow your mobile app can send voice commands to your Windows Jarvis!\n\n---\n\n## Troubleshooting\n\n### \"Microphone not working\"\n- On your Android phone, go to **Settings > Apps > Jarvis > Permissions**\n- Enable **Microphone** permission\n- Restart the app\n\n### \"Can't connect to Windows Jarvis\"\n- Make sure your phone and laptop are on the **same Wi-Fi network**\n- Verify the IP address is correct:\n  ```bash\n  ping 192.168.1.20  # Use your actual IP\n  ```\n- Check that Windows Firewall allows port 8000:\n  - Go to **Windows Defender Firewall > Allow an app through firewall**\n  - Add `python.exe` if it's not listed\n\n### \"Expo Go won't load the QR code\"\n- Make sure your laptop and phone are on the same Wi-Fi\n- Try restarting the dev server: `npm start`\n- Check that `npm install` completed without errors\n\n### \"APK too large to send\"\n- Use cloud storage (Google Drive, OneDrive, etc.)\n- Or scan a QR code from the Expo dashboard on your phone\n\n---\n\n## Commands to Remember\n\n```bash\n# Start development server (use with Expo Go)\nnpm start\n\n# Build an APK for permanent install\neas build --platform android --profile preview\n\n# Run on Android emulator\nnpx expo run:android\n```\n\n---\n\n## Next Steps\n\n✅ Install Expo Go on your phone  \n✅ Run `npm start` on your laptop  \n✅ Scan the QR code  \n✅ Test with voice commands  \n✅ Connect to Windows Jarvis (optional)  \n\n**Need help?** Let me know which step fails! 💪\n"
